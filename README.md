# retrosai-shelves

Per-viewer Game Shelves for [twitch.tv/retrosaieno](https://twitch.tv/retrosaieno).

Whenever the game changes on stream, everyone who is in chat **and** follows the
channel gets that game added to their shelf. Nothing to claim, nothing to type.

* `index.html` - all shelves, the deepest-shelves board, and every game recorded
* `shelf.html?u=<login>` - one viewer's shelf
* `shelves.json` - the same data, if you want to do something else with it
* `art/<system>/<game>.webp` - box-front thumbnails, one per game on a shelf.
  A game entry in `shelves.json` points at its own with an `art` field; games
  with no art simply do not have that field.

Generated by `arcade_publish_shelves.py`. Static snapshot: the pages make no
network requests and do not update themselves.
